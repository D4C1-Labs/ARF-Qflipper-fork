# 🐬 qFlipper ARF

### Graphical desktop application to use the **ARF** firmware on Flipper Zero

---

## ⚠️ Important

> This project is an **unofficial modified version** of qFlipper adapted for the **ARF** firmware.  
>  
> 🌐 Official ARF website: https://arf.d4c1.com/  

---

## 🚀 Description

**qFlipper ARF** is a custom version of qFlipper specifically modified to work with the **ARF** firmware.

This version includes:

- 🎨 A **custom theme (red / ARF style)**
- 🔧 Full support for **ARF firmware**
- ℹ️ A custom **About tab**
- ⚡ A fast and modern interface

---

## 📦 Features

- 🔄 One-click ARF firmware update  
- 🛠️ Repair corrupted firmware  
- 📺 Flipper screen streaming  
- 🎮 Remote control  
- 📁 Install firmware via `.dfu` file  
- 💾 Backup & restore data  
- 🔁 Auto-update system  
- 🖥️ Built-in CLI interface  

---

## ⬇️ Installation

Simply download the file:

👉 **Qflipper-ARF-Setup.exe**

Then:

1. Run the setup  
2. Follow the instructions  
3. Open **qFlipper ARF**  
4. Plug in your Flipper Zero
